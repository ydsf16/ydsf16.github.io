Sensor recordings are useful only when timestamps, coordinate frames and units remain explicit from capture to evaluation.

## A small contract

For a sample at time $t$, the measured state is kept as:

$$
z_t = [a_x, a_y, a_z, \omega_x, \omega_y, \omega_z, t]
$$

The important part is not the vector itself; it is the contract around it:

| Field | Contract |
| --- | --- |
| `t` | Monotonic capture time in seconds |
| `a` | Linear acceleration in m/s², device frame |
| `ω` | Angular velocity in rad/s, device frame |

```swift
struct IMUSample: Codable {
    let timestamp: Double
    let acceleration: SIMD3<Double>
    let rotationRate: SIMD3<Double>
}
```
