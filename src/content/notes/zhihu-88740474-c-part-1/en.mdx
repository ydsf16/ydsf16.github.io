This first note introduces practical C++ concurrency: threads, shared data, mutexes, locks, and the basic reasons race conditions occur.

Correct concurrent code starts with ownership and synchronization design. Keep critical sections small, avoid unstructured shared mutable state, and make thread lifetime and communication explicit.
