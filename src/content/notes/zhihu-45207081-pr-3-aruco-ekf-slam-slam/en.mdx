This project implements EKF SLAM with ArUco fiducial markers. The filter jointly estimates the robot pose and marker positions, using marker observations to correct accumulated motion error.

ArUco markers simplify correspondence, making the project a clear way to study prediction, observation Jacobians, covariance propagation, landmark initialization, and the consistency challenges of EKF SLAM.
